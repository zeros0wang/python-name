# Python 到 Agent 开发学习路线图

这份路线图面向已有 Java 开发经验的工程师。目标不是把 Python 语法背完，而是尽快具备 Python 后端与 Agent 工程开发能力。

## 总目标

完成学习后，你应该能够：

- 熟练阅读和编写常见 Python 业务代码。
- 使用 Python 编写脚本、后端接口、测试和工程化项目。
- 理解 Python 与 Java 在类型、函数、类、异常、包管理上的差异。
- 使用 FastAPI 构建 Agent 服务接口。
- 调用 LLM API，完成工具调用、记忆、RAG、流式输出等 Agent 基础能力。
- 能独立开发一个可运行、可测试、可部署的 Python Agent 项目。

## 阶段 1：Python 基础适应期

目标：从 Java 思维平稳切换到 Python 思维。

建议周期：第 1 天到第 7 天。

重点内容：

- Python 环境、虚拟环境、项目结构。
- 基础类型：`str`、`int`、`float`、`bool`、`list`、`dict`。
- 函数、参数、返回值、默认参数、类型提示。
- 条件判断、循环、列表遍历、字典遍历。
- 文件读写、异常处理。
- Java 与 Python 常见写法对比。

阶段产出：

- 一个结构清晰的 Python 学习仓库。
- 多个小脚本练习。
- 一份 Java 到 Python 对照笔记。

当前进度：

- Day 01：完成第一个交互式 Python 程序。
- Day 02：完成基础类型、`list`、`dict` 练习。
- Day 03：学习函数、参数和返回值。

## 阶段 2：Python 工程化基础

目标：从“能写脚本”过渡到“能写可维护项目”。

建议周期：第 8 天到第 14 天。

重点内容：

- 模块与包：`import`、包目录、模块拆分。
- 类与对象：`class`、构造函数、实例方法。
- 数据建模：`dataclass`、类型提示、简单领域模型。
- 依赖管理：`uv`、`pyproject.toml`。
- 日志、配置、环境变量。
- 单元测试：`pytest`。

阶段产出：

- 一个小型命令行任务管理工具。
- 一套基础测试用例。
- 对 Python 项目结构有明确手感。

## 阶段 3：Python 后端开发

目标：掌握 Agent 服务需要的 Web API 基础。

建议周期：第 15 天到第 24 天。

重点内容：

- FastAPI 基础：路由、请求参数、响应模型。
- Pydantic 数据校验。
- REST API 设计。
- 异常响应与统一错误处理。
- async/await 基础。
- HTTP 客户端调用。
- 简单数据库或文件存储。

阶段产出：

- 一个 FastAPI 后端服务。
- 支持增删改查的业务接口。
- 能用接口方式调用 Python 逻辑。

## 阶段 4：Agent 开发基础

目标：理解 Agent 的核心组成，并用 Python 实现最小可用 Agent。

建议周期：第 25 天到第 35 天。

重点内容：

- LLM API 调用方式。
- Prompt 设计基础。
- Message 历史与上下文管理。
- Tool Calling / Function Calling。
- Agent 执行循环：思考、调用工具、观察结果、继续回答。
- 简单记忆机制。
- 流式输出。

阶段产出：

- 一个命令行 Agent。
- 一个 FastAPI Agent 接口。
- 至少实现 2 个工具，例如时间查询、文件查询、简单计算。

## 阶段 5：RAG 与知识库 Agent

目标：让 Agent 能基于私有文档回答问题。

建议周期：第 36 天到第 45 天。

重点内容：

- 文档加载与切分。
- Embedding 基础。
- 向量检索基本原理。
- 召回、重排、上下文拼接。
- RAG 提示词模板。
- 引用来源与答案可信度。
- 常见失败场景：幻觉、召回不准、上下文过长。

阶段产出：

- 一个本地知识库问答 Agent。
- 支持导入 Markdown 或文本文件。
- 回答时能带来源片段。

## 阶段 6：Agent 工程化与部署

目标：把 Demo 变成更接近真实工作的工程项目。

建议周期：第 46 天到第 56 天。

重点内容：

- 项目分层：API 层、Service 层、Agent 层、Tool 层。
- 配置管理与密钥管理。
- 日志、错误处理、请求追踪。
- 测试：单元测试、接口测试、Agent 行为测试。
- Docker 基础。
- 部署与运行文档。
- 性能和成本意识：缓存、限流、上下文裁剪。

阶段产出：

- 一个可运行的企业知识库 Agent 项目。
- 有 README、测试、配置示例和启动命令。
- 能向别人解释整体架构。

## 每天学习节奏

建议每天按这个顺序推进：

1. 看当天目标，先知道今天解决什么问题。
2. 写代码，不只看语法。
3. 至少运行两次，包含一个正常场景和一个边界场景。
4. 记录 Java 到 Python 的差异。
5. 做一次 Git 提交，保证每天都有可回退节点。

## 学习原则

- 先能跑，再优雅。
- 先用 Java 经验理解，再逐步接受 Python 风格。
- 少背语法，多写小程序。
- 每天都要有一个可验收结果。
- Agent 开发不是只会调 API，更重要的是工程结构、上下文管理、工具设计和可测试性。

## 最终项目

最终项目建议做成：企业知识库 Agent。

它应该包含：

- FastAPI 后端服务。
- 文档导入能力。
- RAG 检索能力。
- LLM 问答能力。
- 工具调用能力。
- 简单记忆能力。
- 测试用例。
- Docker 或本地部署说明。

这个项目能覆盖 Python 基础、后端开发、LLM 调用、Agent 架构和工程化能力，是从 Java 开发者转向 Agent 开发工程师的一条实用路线。
